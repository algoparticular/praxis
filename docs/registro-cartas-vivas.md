# Registro de cartas vivas e interactivas

Estado a 2026-10-31. Verbos: ver `verbos-y-dinamicas.md` (ya guardados en `cards.json`). Fuente de verdad en el código: `src/data/cardScenes.js` (`sceneFor(id)`). Si una carta no está ahí (o no hay WebGL), usa `SceneFlat` (ilustración plana que deriva lento). Cuando una carta pase a viva, se agrega una fila acá en el mismo PR.
